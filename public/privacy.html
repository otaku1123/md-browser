Privacy Policy

MD Browser (web app and Chrome extension) · Last updated: 2026-10-26

Summary

MD Browser does not collect, store, transmit, sell, or share any personal data or file contents. All processing happens locally in your browser.

What the extension accesses

  • Markdown files you open in Chrome (file:///…/*.md): the extension reads the file you are viewing to render it, and re-reads only that same file to detect changes (auto-reload). To list the other Markdown files next to it in the file sidebar, it also reads the folder listings of that file's folder and its subfolders (never parent folders) and keeps only the Markdown file names; it does not read those files until you open one. File contents never leave your computer.
  • Files or folders you pick in the viewer: read locally with the browser's File System Access API, only after you choose them.

Settings

Only your preferences are saved: theme, text size, content width, image size, the font names you entered (for the document body and for code), whether the table of contents and the file sidebar are shown and how wide they are, and the viewer's folder scan limit (how many entries to look through when opening a folder). The extension saves them with chrome.storage.sync, so Chrome may sync them across your signed-in browsers; the web app saves them in your browser's localStorage. While you browse local files, the extension also keeps, per tab in chrome.storage.session, the folder the file sidebar was opened from, so the list stays the same when you move into a subfolder; it is cleared when the tab or the browser is closed.

To reopen your work after a reload, the viewer and the web app also keep, in your browser's IndexedDB, references to up to 10 recently opened files or folders, with their names, when they were opened, and the name of the document that was showing. These stay in your browser and are never synced or sent anywhere; reading the file or folder again still requires the permission you gave in the browser, which you can revoke at any time in the site settings. No file contents or personal data are saved.

What we do not do

  • No analytics, tracking, advertising, or telemetry.
  • No accounts, cookies, or remote servers operated by us.
  • No remote code: all code is bundled in the extension package.
  • Diagrams (Mermaid, PlantUML) and math are drawn inside your browser; nothing is sent to a diagram server such as plantuml.com.

Third-party content in your documents

If a Markdown document embeds images from external URLs (for example https://…/image.png), your browser loads them directly from those servers, as with any web page. MD Browser does not add any requests of its own.

プライバシーポリシー

MD Browser（Web アプリおよび Chrome 拡張機能）· 最終更新日: 2026-10-26

概要

MD Browser は、個人データやファイルの内容を収集・保存・送信・販売・共有しません。すべての処理はお使いのブラウザ内で完結します。

拡張機能がアクセスするもの

  • Chrome で開いた Markdown ファイル（file:///…/*.md）: 表示のために閲覧中のファイルを読み込み、変更の検知（自動更新）のために同じファイルだけを再読み込みします。また、ファイル一覧のサイドバーに同じ場所の Markdown ファイルを表示するため、そのファイルがあるフォルダとその下のフォルダの一覧を読み込み、Markdown ファイルの名前だけを使います（親フォルダは読みません。一覧にあるファイルの中身は、開くまで読みません）。ファイルの内容がパソコンの外に出ることはありません。
  • ビューアーで選択したファイル・フォルダ: ユーザーが選択した後に限り、ブラウザの File System Access API でローカルに読み込みます。

設定の保存

保存するのは設定（テーマ、文字サイズ、本文幅、画像サイズ、入力したフォント名 2 つ（本文用とコード用）、目次とファイル一覧の表示・非表示と幅、ビューアーのフォルダ走査上限（フォルダを開くときに調べる件数））だけです。拡張機能は chrome.storage.sync に保存するため、Chrome にログインしている場合はブラウザ間で同期されることがあります。Web アプリはブラウザの localStorage に保存します。ローカルファイルを表示している間、拡張機能はタブごとに、ファイル一覧の起点にしたフォルダを chrome.storage.session に保持します（サブフォルダに移っても同じ一覧を表示するため）。タブまたはブラウザを閉じると消えます。

また、再読み込み後に作業を再開できるよう、ビューアーと Web アプリは、最近開いたファイル・フォルダ（最大 10 件）への参照と、その名前・開いた日時・表示していた文書の名前をブラウザの IndexedDB に保存します。これらはブラウザ内にだけ残り、同期や送信はされません。ファイル・フォルダを再び読み込むには、ブラウザで与えた許可が必要です（サイトの設定からいつでも取り消せます）。ファイルの内容や個人データは保存しません。

行わないこと

  • アクセス解析・トラッキング・広告・テレメトリは一切行いません。
  • アカウント・Cookie・当方が運営するサーバーはありません。
  • リモートコードは使用しません。すべてのコードは拡張機能のパッケージに含まれています。
  • 図（Mermaid・PlantUML）と数式はブラウザ内で描画します。plantuml.com などの描画サーバーには送信しません。

ドキュメント内の外部コンテンツ

Markdown に外部 URL の画像（例: https://…/image.png）が含まれている場合、通常の Web ページと同様に、ブラウザがその画像をそのサーバーから直接読み込みます。MD Browser が独自に通信を追加することはありません。
